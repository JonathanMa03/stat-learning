# Statistical Learning in R

A hands-on R repository for studying and implementing methods from: 
- **The Elements of Statistical Learning: Data Mining, Inference, and Prediction** 
— **An Introduction to Statistical Learning: with Applications in R** 

## Demos

Each demonstration has its own standalone `.R` script.

A typical script contains:

1.  Data loading or data generation
2.  Exploratory visualization
3.  Model or algorithm implementation
4.  Model fitting
5.  Prediction or inference
6.  Evaluation
7.  Visualization of results

Where practical, scripts are self-contained and can be run independently.

## Writeups

Longer exercises, comparisons, experiments, and applications are contained in `.Rmd` files.

The writeups are intended to document practical experiments and results rather than reproduce textbook notes.
